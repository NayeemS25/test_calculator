# Simple Calculator

A clean, responsive calculator web app built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## Features

- Addition, subtraction, multiplication and division
- Percent, sign toggle (±), decimal point, delete (⌫) and clear (AC)
- Chained operations (`2 + 3 × 4 =` works left to right, like a pocket calculator)
- Handles divide-by-zero and floating-point noise (`0.1 + 0.2 = 0.3`)
- Keyboard support
- Light and dark mode (follows your system setting)
- Works on phones and desktops

## Run it

Open `index.html` in any browser. That's it.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `0`–`9` | Digits |
| `+` `-` `*` `/` | Operators |
| `.` | Decimal point |
| `Enter` or `=` | Calculate |
| `%` | Percent |
| `Backspace` | Delete last digit |
| `Esc` or `Delete` | Clear all |
